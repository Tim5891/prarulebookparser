ℹ️ Help

How to use:

  1. Step 1: Enter a date in dd-mm-yyyy format and select a layer (sector, part, chapter, or rule)
  2. Step 2: Click "Scrape Structure" to get the rulebook hierarchy
  3. Step 3: Copy a URL from the results and paste it in Step 2
  4. Step 4: Select content type (text for reading, links for network analysis)
  5. Step 5: Click "Get Content" to extract the data
  6. Step 6: Export results as CSV for further analysis

Available Dates:

Any date from 01-01-2005 to today in dd-mm-yyyy format

Data Formats:

  • Structure: Hierarchy with sector, part, chapter names and URLs
  • Text: Rule numbers and text content
  • Links: Network data (from/to URLs and link types) for network analysis

Examples:

  • 16-11-2007 - Early handbook date
  • 29-08-2015 - Transition from Handbook to Rulebook
  • 18-06-2019 - Recent rulebook snapshot
